# Who opened a share link

Every link you hand out — a Facebook post's **preview**, an offer's **specification**, a
**proposal**, a sale's **buyer link** and a trade's **partner link** — keeps a record of each time it
was opened. It answers what *last opened* alone could not: one look on the day and ten from different
places no longer read the same.

## In the link's dialog

The line under the link says when it was made, when it was last opened and how often, to the minute
and in your own time zone:

> Created 17 Nov 2026, 14:02 · last opened 17 Nov 2026, 18:45 · 7 visits

**Your own opens are counted apart.** Opening the link while you are signed in here — **Open as the
buyer sees it** included — is recorded and marked *You*, but it does not make *last opened* and is
added after the count (*7 visits + 2 yours*), so checking the link yourself is never mistaken for a
buyer reading it.

## Visit history

**Visit history**, beside that line, opens every visit in its own window, newest first: the time, the
visitor's **IP address** exactly as it arrived (no lookup of who or where it is), and the **browser and
system** it came from — *Chrome · Android*, *Safari · iOS*, *Facebook app · Android*. Hover the browser
to see the full text the browser sent.

- **A visit is an opening of the page**, a reload included. The photos and files the page loads are
  not visits, and moving around inside a page already open (the grouping chips on a trade's page) is
  not a new one.
- **A link pasted into a message is often fetched before anyone taps it.** Facebook, Messenger and
  WhatsApp read the page to draw a preview of it; those visits are named *Facebook link preview*,
  *WhatsApp link preview* and so on, so you can tell them from the buyer.
- **New link keeps the old link's visits.** The history lists them under *Replaced link*, and if
  somebody still opens the old address — they are told it no longer works — that visit is recorded
  there too.
- **Withdraw keeps them as well**, under *Withdrawn link*, and an opening of a withdrawn link is
  recorded. After a withdrawal the dialog has no link, but **Visit history** is still there while the
  old link has visits.

The buyer's page does not change and says nothing about visits being recorded.

## How long visits are kept

**90 days.** An IP address is a buyer's personal data, so each visit is removed 90 days after it
happened, and the count and *last opened* cover what is still kept. A replaced or withdrawn link with
no visits left disappears from the history.
