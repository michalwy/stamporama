Stamporama Assistant

A profile is one Stamporama instance plus one collection — a dev server and your production instance are separate profiles, and so are two collections on the same instance. The extension only ever talks to the active one. The easy way to add one is to open Settings → Assistant in Stamporama, click Connect Stamporama Assistant, then click this extension's toolbar icon — the instance registers itself, with nothing to type. The form below is the manual alternative.

Each profile gets its own colour, derived from the instance and collection it points at, and that colour follows it into the Assistant window — so the target you are about to write to is recognisable at a glance.

Behaviour

Registering from Stamporama's settings exchanges a one-time code for a token that is stored here and revocable there (Stamporama issue #252). Registering the same instance and collection again refreshes that profile's token in place — that is how you replace a token you revoked or lost.
